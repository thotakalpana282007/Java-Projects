## 📌 Projects Included

### 🎮 Guess The Number Game

A console-based Java game where:

- The computer generates a random number
- The user tries to guess the number
- The program gives hints (Too High / Too Low)
- Tracks number of attempts

### Concepts Used:

- Loops
- Conditional statements
- Random class
- Scanner class
- Logic building

---
### 🎮 Tic Tac Toe Game

A two-player console-based Java game where:

- Two players take turns (X and O)
- The game runs on a 3x3 board
- Checks for win conditions (rows, columns, diagonals)
- Detects draw situations

### Concepts Used:

- Arrays
- Loops
- Conditional statements
- Methods
- Game logic building
